# vtori.ink (Resumo)

Landing page premium para a tatuadora **Vitória Lima**.

### **Foco**
- Estilos: Fineline, Blackwork, Geek.
- Localização: Juiz de Fora, MG.

### **Stack**
React 19 + Vite + Framer Motion + Vanilla CSS.

### **Seções Principais**
1. Portfólio Filtrável.
2. Agendamento via WhatsApp/Formulário.
3. Feed Instagram (Slider).
4. Flash Designs Disponíveis.

### **Execução Rápida**
```bash
npm install
npm run dev
```
